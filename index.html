A small libretro frontend for playing games.

No library to build, no playlists to scan. Pick a core, pick a game, play. piccolo puts its effort where you notice it: smooth timing, sharp pixels, controls that do what you want, and a classic emulator look.

Coming in December Source on GitHub

What it does

LOAD GAME

Choose a core first, then a file. The list shows only what that core can load, asked from the core itself. Games inside zip and 7z archives work too, and RECENT keeps your last games one click away.

Timing that feels right

Vsync or exact timing, frame delay with an automatic search per game, run-ahead, low latency presentation and dynamic rate control so sound never crackles.

Sharp pixels

Aspect ratio, integer or automatic scaling, filters and overscan crop, with a live preview in IMAGE SETTINGS. Picture controls, and a short list of shaders we picked, run through librashader.

Savestates

Nine slots per game with thumbnails and dates in the QUICK MENU. Save RAM and states are kept for you.

Your controls

One controller per port, remaps per core with per-game copies, turbo, combos, macros you record, mouse and lightgun, and a MAP CONTROLLER wizard for unknown pads.

Settings in layers

Every setting is global, and many can be set for one core or one game. Core options can be kept per core, per folder or per game.

Cores in one place

TOOLS > CORES downloads and updates libretro cores, with signed downloads. Cores under non-free licenses stay hidden until you ask for them.

Phones as controllers

Pair a phone with a 6-digit code and choose what it may do: be a gamepad, play the game streamed to it, or browse your games and load them. Encrypted, on your own network.

A retro-style UI

A menu bar, windows and a 5×5 pixel font drawn for piccolo. Themes: BLUE, PURPLE, ZSNES and BLACK, or your own.

Small and fast

Native code on Vulkan, tested on a low-end ARM board. Linux, Windows, Android and Android TV. English and Spanish.

piccoletto

piccolo's companion app, for Android first.

piccoletto pairs with a piccolo on your network and does what that piccolo lets it. It never runs games itself: the game always runs on piccolo.

GAMEPAD

Your phone becomes a controller on any of piccolo's ports, with buttons you can move. A gamepad connected to the phone works too.

REMOTE PLAY

piccolo streams the picture and the sound to the phone, which plays it with touch or a gamepad, and with piccolo's shaders.

DEVICES

See who is playing on which port and move phones and controllers between ports from the couch.

Ships alongside piccolo, for Android phones and Android TV.

Get it

The first release is planned for early December: piccolo for Linux (Flatpak), Windows and Android, and piccoletto for Android. Until then you can build piccolo from source; you'll need CMake, Ninja, a C++20 compiler and the Vulkan SDK.

git clone --recursive https://github.com/multitap-org/piccolo.git
cd piccolo
cmake -S . -B build -G Ninja -DCMAKE_BUILD_TYPE=Release
cmake --build build
./build/piccolo

piccolo runs libretro cores: bring the cores and the games you own.
